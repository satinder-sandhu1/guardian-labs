# MCP Security

Research into Model Context Protocol trust boundaries, servers, clients, tools, resources, identity, authorization, and capability exposure.

## Research areas

- Malicious or compromised MCP servers
- Tool poisoning
- Capability overreach
- Authentication and authorization
- Secret exposure
- Cross-server trust
- Tool description manipulation
- Unsafe command execution

## Guardian question

**Can an AI system distinguish trusted capabilities from hostile or over-privileged ones?**
