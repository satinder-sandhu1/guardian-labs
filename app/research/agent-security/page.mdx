# Agent Security

Guardian Labs studies AI systems that can reason, plan, remember, invoke tools, access data, delegate work, and take actions with real-world consequences.

## Research areas

- Excessive agency
- Tool misuse
- Privilege and authorization failures
- Confused-deputy behavior
- Unsafe delegation
- Memory poisoning
- Multi-agent trust failures
- Human approval bypass

## Guardian question

**Can the system still be kept within intended boundaries when conditions become adversarial?**
