# Model Security

Research into security properties of models and the systems that train, distribute, fine-tune, and execute them.

## Research areas

- Model extraction
- Data poisoning
- Backdoors
- Adversarial examples
- Evasion
- Model supply-chain security
- Unsafe model loading
- Integrity verification
- Fine-tuning risk

## Guardian question

**Can the model and its surrounding supply chain be trusted under adversarial pressure?**
